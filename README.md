# the-aussie-outfit-frontend

A React + Vite frontend project built entirely with JavaScript.

## Features

- React 18 with Vite for fast development and building
- JavaScript-only codebase (no TypeScript)
- ESLint support for code quality
- Hot Module Replacement (HMR) enabled in development

## Getting Started

### Prerequisites

- Node.js 16 or later
- npm or yarn

### Install dependencies

```bash
npm install
```

or

```bash
yarn install
```

### Run the development server

```bash
npm run dev
```

or

```bash
yarn dev
```

### Build for production

```bash
npm run build
```

or

```bash
yarn build
```

### Preview the production build

```bash
npm run preview
```

or

```bash
yarn preview
```

## Project Structure

- `src/` - source files for the React application
- `public/` - static assets
- `index.html` - application entry HTML file
- `vite.config.js` - Vite configuration

## Notes

This repository is intentionally configured as a JavaScript project without TypeScript.
